# Miskat Hossain — Portfolio & Digital Experiences

> Premium, highly interactive personal portfolio website for **Miskat Hossain** (Brand & Web Designer).

Built with **Next.js**, **React**, **TypeScript**, **Tailwind CSS**, **GSAP ScrollTrigger**, and **Lenis**.

---

## ✨ Features

- **Cinematic Scroll-Scrubbed Hero**: 240 full-HD frame image sequence mapped to scroll progress with smooth interpolation and zero video-seeking latency.
- **Editorial Glassmorphism UI**: Refined floating cards with backdrop-blur, subtle inner highlights, and suit lapel rose accent (`#E0284F`).
- **Scene-Based Project Presentation**: High-impact storytelling scenes for commercial client projects (TeamsOfMen, Christopher Miller, Cara Walker, Midwest Crochet Society, Tamika).
- **Comprehensive Case Studies (`/work/[slug]`)**: 8-part design presentation layout (`HERO` &rarr; `CHALLENGE` &rarr; `THINKING` &rarr; `DIRECTION` &rarr; `IDENTITY` &rarr; `WEBSITE` &rarr; `RESULT` &rarr; `NEXT PROJECT`).
- **Interactive 3D Visual System Object**: Lightweight mathematical coordinate canvas object responding to mouse parallax, symbolizing brand grids and spatial typography.
- **Desktop Custom Cursor**: Non-intrusive magnetic cursor with contextual hover labels (`VIEW`, `EXPLORE`, `CASE STUDY`, `COPY`, `TALK`).
- **Lenis Smooth Scroll**: Butter-smooth scrolling synchronized directly with the GSAP ScrollTrigger ticker.
- **Vercel & Production Ready**: Pre-rendered with static generation (SSG) across all routes, dynamic sitemap (`/sitemap.xml`), and robots (`/robots.txt`).

## 🛠 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animation**: [GSAP](https://gsap.com/) & [ScrollTrigger](https://gsap.com/scrolltrigger/)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
